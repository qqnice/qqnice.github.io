🎮 Unreal 教學專區

這裡整理 Unreal Engine 5 的入門與 Blueprint（視覺化腳本）教學，以及課堂使用的實作教材。內容以 Blueprint 為主，不需要先會寫 C++。

🧭 建議的學習順序

STEP 1 入門：安裝、專案與介面 安裝引擎、建立第一個專案、認識編輯器各個面板與視埠操作。 STEP 2 Blueprint 基礎 事件、變數、函數、流程控制，以及 Actor 之間如何溝通。附一個可動手做的小練習。 速查 快捷鍵、除錯與常見問題 視埠與 Blueprint 快捷鍵（依官方文件整理）、除錯方法與常見狀況排解。 實作演練 ElevatorKit 學生操作手冊 用 Blueprint 寫出兩層樓電梯的行為，分四個關卡：會動、門、燈與顯示器、請求排隊與擋門。手冊以課程提供的 ElevatorKit 檔案為前提。 互動實驗 電梯狀態實驗室 操作樓層呼叫與擋門，透過動畫、單步觀察與三個實驗，理解五個狀態的動作及切換條件。 聲光進階版 電梯狀態機 · 聲光與藍圖互動實驗室 結合即時音效、關卡 1～4 漸進切換、Unreal Switch on Int 白線追蹤與「常見接錯線 Bug 診所」，深入理解狀態機與藍圖結構。

🚀 如何使用本專區

  • 📄 點擊 .html 頁面：直接閱讀該單元。
  • 📁 點擊資料夾：進入該主題的教材（例如 unrealev/ 是 ElevatorKit 手冊）。
  • ➕ 新增內容：把新的 .html 放進 unreal/ 資料夾，推送後下方目錄會自動更新。若檔案開頭加上 title 與 description 兩個欄位（front matter），目錄就會顯示標題與說明，而不是檔名。
