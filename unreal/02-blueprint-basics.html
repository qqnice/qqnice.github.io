Blueprint 基礎：事件、變數、函數與流程控制

Blueprint 用「節點」與「連線」表達邏輯。本頁說明它的基本組成，讓你讀得懂別人的 Blueprint，也能自己寫出第一個有行為的 Actor。

1. Blueprint 有哪幾種

類型用途
Blueprint Class最常用。定義一種 Actor（或 Pawn、Character 等）的外觀與行為，可重複放進場景。教材中的 BP_ElevatorKit 就是這一種。
Level Blueprint附屬於單一關卡的腳本，適合只在該關卡才有的一次性邏輯。
Blueprint Interface只定義「函數的名稱與參數」，讓不同類型的 Actor 用同一種方式被呼叫。
Blueprint Function Library放不依附特定物件、可到處呼叫的共用函數。
Macro Library放可重複使用的巨集（一段可展開的節點組合）。
Widget BlueprintUMG 介面（按鈕、文字、血條等 UI）。
Animation Blueprint控制角色動畫的狀態與混合。

2. Blueprint 編輯器的主要區域

雙擊 Content Browser 中的 Blueprint 即可開啟。幾個最常用的區域：

  • Components：這個 Blueprint 由哪些零件組成（模型、碰撞區、燈光等）。
  • My Blueprint：變數、函數、巨集、事件分派器都在這裡建立與管理，雙擊就能開啟。
  • 圖表區（Event Graph / 函數圖表）：拉節點、接線的地方。
  • Details：顯示選取項目的設定，例如變數的型別與預設值。
  • Compile 與 Save：改完要按 Compile（F7）檢查錯誤，再用 Ctrl + S 存檔。編譯不等於存檔。

3. 兩種線：執行線與資料線

  • 白色的執行線決定「先做什麼、再做什麼」，從事件節點開始，一個節點接著一個節點往下跑。
  • 彩色的資料線負責傳遞數值，顏色代表資料型別。沒有接白線的純計算節點，會在被需要時才計算。

最小的範例：Event BeginPlay → Print String（文字填「Hello」）。試玩時畫面左上角會出現 Hello，這就是「遊戲開始時做一件事」。

4. 變數

在 My Blueprint 的 Variables 旁按 ＋ 新增變數，再到 Details 設定名稱、型別與預設值。常見型別：

型別放什麼
Boolean真／假，例如「門是否開著」。
Integer整數，例如樓層、分數。
Float帶小數的數值，例如速度、時間。
String / Name / Text文字。Text 用於要顯示給玩家看的內容，Name 用於內部識別。
Vector / Rotator / Transform位置或方向（Vector）、旋轉（Rotator）、位置＋旋轉＋縮放（Transform）。
Object Reference指向另一個 Actor 或物件的參照。

兩個常用的變數選項：

  • Instance Editable（眼睛圖示）：勾選後，放進關卡的每一個實例都能在 Details 中各自調整這個值。
  • Expose on Spawn：勾選後，用程式動態產生這個 Actor 時，可以直接帶入初始值。

把變數拖進圖表時：按住 Ctrl 拖曳是取值（Get），按住 Alt 拖曳是設值（Set）。

5. 事件：什麼時候開始執行

事件何時觸發
Event BeginPlayActor 開始存在於遊戲中時，執行一次。
Event Tick每一個畫面更新都執行，並提供 Delta Seconds（距離上一幀經過的秒數）。
Event ActorBeginOverlap有其他 Actor 與它的碰撞範圍重疊時（需要碰撞設定允許產生重疊事件）。
輸入事件玩家按鍵或操作時。UE5 的輸入系統為 Enhanced Input，核心概念是 Input Action（玩家能做的動作）與 Input Mapping Context（哪些按鍵對應哪些動作）。
Custom Event你自己定義的事件，可以從別處呼叫，也能搭配計時器使用。
Event Dispatcher事件分派器：一個 Blueprint 對外「廣播」，其他 Blueprint 可以綁定並接收通知。

Enhanced Input 的細節請見 Enhanced Input in Unreal Engine（Epic 官方文件）；預設啟用狀態與樣板專案的設定可能依引擎版本而異，請以你使用的版本為準。

6. 函數、巨集與自訂事件怎麼選

種類特點適合
Function（函數）可以有輸入與輸出參數、區域變數；不能放 Delay 這類需要等待的節點。可重複使用、有明確輸入輸出的計算或動作。
Macro（巨集）可以有多個執行輸入與輸出腳位。想要把一段節點組合收納起來重複使用。
Custom Event（自訂事件）位於 Event Graph，可搭配 Delay、計時器等。需要等待或分段執行的流程。

7. 常用的流程控制節點

節點作用
Branch依條件（Boolean）走 True 或 False 兩條路。
Sequence依序執行多條輸出線。
ForLoop / ForEachLoop重複執行；ForEachLoop 逐一處理陣列中的每個元素。
Switch（如 Switch on Int）依數值或列舉，分流到不同出口。適合表示「狀態」。
Select依條件從多個值中挑一個出來，是資料節點，沒有執行線。
Do Once / Gate只讓流程通過一次／可開關的閘門，常用來避免重複觸發。
Delay / Set Timer by Event延遲一段時間再執行；或每隔固定時間重複執行。

8. Actor 之間如何溝通

做法說明什麼時候用
直接參照＋ Cast To取得另一個 Actor 的參照，用 Cast To 確認它的類型後，呼叫它的變數或函數。兩者關係固定、類型明確。
Blueprint Interface不管對方是什麼類型，只要實作了介面就能用同一個函數呼叫。要和多種不同類型的 Actor 溝通。
Event Dispatcher發出者廣播，接收者自己綁定事件。發出者不必知道誰在聽。一對多通知，例如「電梯到達」通知多個顯示器。

避免在 Tick 裡做重的事。像 Get All Actors Of Class 需要走訪關卡內所有 Actor，不適合每一幀都呼叫。能用事件或計時器解決的，就不要放在 Tick。

9. 好習慣

  • 邏輯變複雜時，選取節點按 C 加上註解框，並把長邏輯拆成函數。
  • 變數、函數用有意義的名稱，例如 IsDoorOpen 而不是 Bool1。
  • 每次大改完就 Compile，錯誤愈早發現愈好處理。
  • 與時間相關的移動或旋轉，要乘上 Delta Seconds，速度才不會因為電腦快慢而不同。

10. 動手做：會自己旋轉的方塊

目標：做一個每秒旋轉固定角度、而且每個實例都能自己調速度的方塊。

  1. 在 Content Browser 按右鍵 → Blueprint Class → 選 Actor，命名為 BP_RotatingCube，雙擊開啟。
  2. 在 Components 按 Add，新增一個 Static Mesh 元件，到 Details 的 Static Mesh 欄位選 Cube。
  3. 在 My Blueprint 新增一個 Float 變數 RotationSpeed，勾選 Instance Editable，預設值設 45，代表每秒轉 45 度。
  4. 在 Event Graph 中，從 Event Tick 拉出白色執行線，接上 Add Actor Local Rotation。
  5. 把 Delta Rotation 展開（或拆開），在 Yaw 填入 RotationSpeed × Delta Seconds（用 Ctrl 拖入變數取值，再接乘法節點）。
  6. 按 Compile，再 Save。把 BP_RotatingCube 從 Content Browser 拖進關卡，按 Play 試玩。
  7. 放進第二個實例，在 Details 把它的 RotationSpeed 改成 180，觀察兩個方塊轉速不同。

想一想：如果不乘 Delta Seconds，在效能不同的電腦上旋轉速度會有什麼差別？
