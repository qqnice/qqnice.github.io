3. 除錯方法

  • Print String：最簡單的除錯工具。在可疑的位置接一個 Print String，把變數值或「走到這裡了」印出來。訊息可以顯示在畫面上，也會寫進 Output Log。
  • Output Log：從選單 Window → Developer Tools → Output Log 開啟，查看執行時的訊息與警告。
  • Compile 訊息：Blueprint 編譯有錯誤時，錯誤節點會標示出來，先修掉再試玩。
  • 斷點：選取節點按 F9 設斷點，試玩時執行到那裡會暫停，可以在暫停時檢視變數數值。
  • 觀察數值：在腳位上按右鍵，可以選擇監看（Watch）該數值，執行時就能即時看到它的變化。

4. 常見狀況

狀況可以檢查
按 Play 之後我的 Blueprint 沒反應Blueprint 是否有放進這個關卡？事件節點是否有接上白色執行線？是否已 Compile？
兩個節點連不起來資料型別不相容（例如把文字接到數值）。從腳位拖出連線後，搜尋視窗只會列出可以接的節點，可善用它。
改了 Blueprint 的預設值，場景中的實例卻沒變該實例的 Details 可能已經手動覆寫了那個值；數值旁會出現可還原成預設值的箭頭，按下即可。
同一個事件被重複觸發Overlap 事件可能因為物件有多個碰撞元件而觸發多次，可用 Do Once 或檢查是哪個 Actor 觸發的。
忘記存檔就當機到專案資料夾的 Saved/Autosaves 看看有沒有自動存檔可以救回。
編輯器很慢／專案資料夾很大Saved、Intermediate、DerivedDataCache 是可重建的快取；備份或傳送專案時可以不帶。
