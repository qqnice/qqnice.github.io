Unreal Engine 5 入門：安裝、專案與介面

本頁帶你從零開始：把引擎裝起來、建立第一個專案、看懂編輯器的主要面板，並學會在場景裡移動視角與擺放物件。

1. Unreal Engine 是什麼

Unreal Engine 是即時 3D 引擎，常用於遊戲、互動體驗、建築與產品視覺化、影視製作，以及教學模擬。在引擎裡撰寫邏輯有兩種方式：

  • Blueprint：用節點與連線組成邏輯的視覺化腳本，不用寫程式碼，適合入門與快速試作。
  • C++：傳統程式語言，適合底層系統與效能要求高的部分。

兩者可以混用。本專區的教材以 Blueprint 為主。

2. 安裝引擎（以 Windows 為例）

  1. 安裝並登入 Epic Games Launcher。
  2. 在 Launcher 的 Unreal Engine 分頁，進入 Library（資源庫），新增並安裝你要使用的引擎版本。
  3. 安裝完成後，從同一頁啟動編輯器。

版本要統一。同一門課或同一個團隊請使用相同的引擎版本。專案被較新的版本開啟並存檔後，通常無法再用舊版開啟。

引擎與專案快取都相當佔空間，建議安裝在 SSD 並預留充足容量。介面文字可能因版本而略有不同，以你安裝的版本為準。

3. 建立第一個專案

  1. 啟動編輯器，在專案瀏覽畫面選擇 Games 類別。
  2. 選一個範本。初學建議選 Third Person（第三人稱）或 First Person（第一人稱），範本已附可操控的角色，按下 Play 就能走動；也可以選 Blank 從空白開始。
  3. 專案類型選 Blueprint（若要寫 C++ 才選 C++）。
  4. 設定專案名稱與儲存位置，按下 Create。

路徑建議使用英文、不含空白與特殊符號，並避免路徑過長，可減少日後與外部工具、版本控制搭配時的問題。

4. 編輯器介面：六個你最常用的區域

區域用途
Viewport（視埠）中央的 3D 場景視窗，在這裡觀察與擺放物件。
Outliner（大綱）列出目前關卡中所有的 Actor，可在這裡選取、改名、整理資料夾。
Details（細節）顯示目前選取物件的所有屬性，例如位置、旋轉、縮放、材質。
Content Drawer / Content Browser專案資產（模型、材質、Blueprint、地圖）的檔案總管。可用 Ctrl + Space 叫出或收起 Content Drawer。
Place Actors（放置 Actor）從選單 Window → Place Actors 開啟，內有方塊、光源、攝影機等常用物件，可直接拖進場景。
工具列存檔、Play（試玩）等常用按鈕。按 Esc 結束試玩。

5. 視埠操作

以下依 Epic 官方文件整理（透視視圖，預設快捷鍵）。如果你在編輯器偏好設定中改過快捷鍵，實際操作可能不同。

想做的事操作
環視場景按住滑鼠右鍵拖曳
飛行移動按住滑鼠右鍵，再按 W A S D；E 上升、Q 下降
調整飛行速度按住右鍵時轉動滾輪
聚焦到選取的物件F
繞著物件旋轉觀察Alt + 按住左鍵拖曳
推近／拉遠Alt + 按住右鍵拖曳
平移視角按住滑鼠中鍵拖曳
切換移動／旋轉／縮放工具W 移動、E 旋轉、R 縮放（沒有按住右鍵時）；Q 為選取工具

來源：Viewport Controls in Unreal Engine（Epic 官方文件）

6. 幾個必懂的名詞

名詞意思
Level（關卡／地圖）一個場景，存成 .umap 檔。
Actor可以放進關卡的物件，例如方塊、光源、攝影機、角色。
Component（元件）組成 Actor 的零件，例如模型、碰撞區、燈光。Actor 本身就是一組元件的容器。
Static Mesh不會變形的靜態 3D 模型。
Material（材質）決定模型表面外觀（顏色、粗糙度等）。
Blueprint Class用 Blueprint 定義的 Actor 範本：外觀（元件）加上行為（邏輯），可重複放進多個場景。
Pawn / CharacterPawn 是可以被玩家或 AI 控制的 Actor；Character 是帶有行走移動功能的 Pawn。
Game Mode定義這個關卡的遊戲規則，包括玩家一開始控制哪一種 Pawn。

7. 專案資料夾與版本控制

MyProject/
├─ MyProject.uproject   ← 專案檔，雙擊即可開啟
├─ Content/             ← 所有資產（.uasset、.umap），最重要
├─ Config/              ← 專案設定
├─ Saved/               ← 日誌、自動存檔（可重建）
├─ Intermediate/        ← 暫存（可重建）
├─ Binaries/            ← 編譯產物（可重建）
└─ DerivedDataCache/    ← 快取（可重建）

備份或放進 Git 時，一般只需要 .uproject、Content/、Config/（有 C++ 時再加 Source/）；Saved、Intermediate、Binaries、DerivedDataCache 通常列入忽略。.uasset 與 .umap 是二進位檔，常見做法是搭配 Git LFS。

養成習慣：資產命名加上類型前綴，例如 BP_（Blueprint）、SM_（Static Mesh）、M_（Material），專案變大之後會很好找。這是社群常見的慣例，不是引擎強制規定。

8. 動手做：第一次試玩與擺放物件

  1. 用 Third Person 範本建立專案，等編輯器開啟。
  2. 按工具列的 Play 試玩，用 W A S D 操控角色，按 Esc 結束。
  3. 在 Outliner 或視埠中點選場景裡的一個方塊，到 Details 看它的 Location / Rotation / Scale。
  4. 用 W、E、R 切換工具，拖曳座標軸移動、旋轉、縮放它；觀察 Details 的數值如何同步變化。
  5. 從 Place Actors 拖一個 Cube 進場景，再次試玩，確認角色會被它擋住。
  6. 按 Ctrl + S 存檔。
