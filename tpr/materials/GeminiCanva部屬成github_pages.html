免費上架你的 AI 靜態網頁

這份互動指南將帶你從零開始，透過 GitHub Pages 部署你的網站，並徹底清除 AI 生成的痕跡。準備好就開始勾選步驟吧！

這就像是去申請一個免費的網路空間帳號。

  1. 前往 GitHub 官方網站 。
  2. 點擊右上角的 「Sign up」 註冊。
  3. 依序輸入你的 Email 與設定密碼。
  4. 重要技巧：設定 Username
    請想一個專屬的英文名稱（例如：myweb2026）。
    這會直接決定你未來的網址！
  5. 通過機器人驗證，並到信箱收取 8 位數驗證碼啟用帳號。

在把網頁放上去之前，我們要先在自己的電腦上把「AI 生成的蛛絲馬跡」清理乾淨。

  1. 將 Gemini 生成的 HTML 程式碼完整複製。
  2. 打開電腦的文字編輯器（Windows 用「記事本」，Mac 用「TextEdit」並設定為純文字）。
  3. 貼上程式碼，按下 Ctrl + F 進行搜尋與刪除：
    • 刪除 AI 註解：尋找 <!-- Generated by Gemini -->
    • 刪除 Meta 標籤：尋找並刪除整行 <meta name="generator" content="Gemini">
    • 檢查 <title> 標籤，確保標題是你的網站名稱，而不是「Gemini 產出」。
  4. 儲存檔案的關鍵：
    請選擇「另存新檔」，存檔類型選「所有檔案(*.*)」，編碼選「UTF-8」。
    檔名必須命名為：
    index.html
  1. 在 GitHub 登入狀態下，點擊右上角的 「+」 號，選擇 「New repository」。
  2. 填寫資料夾名稱（最重要的一步！）：
    為了讓網址最漂亮，請將名稱命名為 你的帳號.github.io。
    例如：你的帳號是 myweb2026，請輸入 myweb2026.github.io
  3. 權限保持勾選 Public（公開）。
  4. 勾選 「Add a README file」。
  5. 滑到最下方，點擊綠色的 「Create repository」 按鈕。
  1. 在剛建立好的專案頁面中，點擊中間的 「Add file」，選擇 「Upload files」。
  2. 畫面會出現一個虛線框。把你剛剛在桌面存好的 index.html 檔案，拖曳到虛線框裡面。
    📁 拖曳檔案到這裡 (示意圖)
  3. 等待檔案傳輸進度條跑完。
  4. 不用填寫任何備註，直接點擊下方綠色的 「Commit changes」 按鈕儲存。

☕ 泡杯茶，稍微等一下

GitHub 收到你的檔案後，後台需要大約 1 到 2 分鐘 的時間來部署網站。

🎉 瀏覽你的專屬網站

打開瀏覽器新分頁，輸入你剛剛設定的網址格式：

https://你的帳號.github.io
💡 如果剛剛第三步名稱不是取 帳號.github.io 怎麼辦？

1. 點擊專案頁面上方的 「Settings」 (齒輪)。

2. 左側選單找到 「Pages」 點進去。

3. 在 Branch 區塊，把 None 改選為 main，點擊右側 Save。

4. 等待 2 分鐘重整頁面，頂端就會出現你的網站專屬網址了！
