📘 TPR 教學實踐專區

這裡收納與教學實踐研究（TPR）相關的資訊：計畫制度的整理、申請與執行時的注意事項，以及個人教學實踐研究的紀錄與教材。

🧭 目前的內容

操作教學 GPT × GitHub：用提示詞發佈網站 從連接 GitHub 插件、檢查儲存庫權限，到複製提示詞建立與更新 GitHub Pages，附發佈後驗收步驟。 互動教學 GitHub 帳號申請與兩階段驗證 給學生與老師的逐步操作手冊：註冊、電子郵件驗證、驗證器 App 與復原碼，附 GitHub 官方畫面與連結。 AI 研究工作流 AI協助研究的工作流 以教學實踐研究計劃的發想、文獻驗證、計劃撰寫以及日後的投稿為主題。講者：資訊管理系 林文彥。附研究教材、工具與執行投稿工作台。 制度整理 教學實踐研究計畫是什麼 計畫的依據、目的、研究類型，以及 114 年度公文中的重點，附原始文件連結。 資料彙整 其他教學資料 AI 協作與反思評量、Gemini 引導學習模式、Notion 指南、AI 題庫等，從 Linux 專區移入。

本站是公開網站。放進這個專區的內容任何人都看得到。請不要放含學生姓名、學號、成績或可辨識個人的資料，也不要放尚未取得同意的問卷與訪談原始資料；需要呈現時請先去識別化。

🚀 如何使用本專區

  • 📄 點擊 .html 頁面：直接閱讀該單元。
  • 📁 點擊資料夾：進入該主題的資料。
  • ➕ 新增內容：把新的 .html 放進 tpr/ 資料夾，推送後下方目錄會自動更新。若檔案開頭加上 title 與 description 兩個欄位（front matter），目錄就會顯示標題與說明，而不是檔名。
