手動發布

GitHub 有修改時，網站會保留目前版本。由你在 GitHub 按下「Run workflow」，才開始更新。

  1. 開啟下方發布頁面，登入有發布權限的 GitHub 帳號。
  2. 按「Run workflow」，分支選 master，再按綠色的「Run workflow」。
  3. 等待建置與發布都顯示成功，再回來開啟網站。
前往 GitHub，手動發布 ↗

此連結只開啟發布頁面，不會直接開始更新。發布權限由 GitHub 驗證。

這次更新會做什麼？

不需要重新使用 AI 生成網站。若發布失敗，請開啟該次執行紀錄查看原因。
