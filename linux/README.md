# 🐧 QQ 老師的 Linux 教學分享區

歡迎來到 **QQ 老師的 Linux 教學分享區**！這裡是我專為探索 Linux 系統與伺服器管理所打造的互動式學習天地。

本網站的核心理念是結合 **Generative AI (Google Gemini)** 的強大輔助與 **Canva** 的視覺化互動設計，為學習者帶來更直覺、更生動的技術體驗。所有的教材、筆記與靜態網頁皆透過 GitHub Pages 進行開源分享與展示。

## ✨ 網站特色與教學亮點

* **🤖 AI 賦能教學 (AI-Assisted Learning)：** 
  教材內容運用 Gemini 協助生成與架構，並融入「AI 輔助程式開發 (Vibe Coding)」的現代思維，帶領學生體驗如何善用 AI 工具提升系統管理與指令編寫的效率。
* **🎨 互動式視覺體驗：** 
  打破傳統終端機枯燥的純文字印象！透過 Canva 設計的互動式網頁與圖解，將抽象的系統架構與操作流程具象化，讓學習過程一目了然。
* **💻 聚焦現代主流環境：** 
  教學內容以實務應用為導向，並以最新、最穩定的 **Ubuntu 24.04 LTS** 為主要實作平台，確保學生所學能與業界標準無縫接軌。
* **📂 直覺的目錄導覽：** 
  網站首頁已導入動態抓取 GitHub API 的技術，提供宛如雲端硬碟般的直覺檔案列表，讓訪客能輕鬆點擊並瀏覽各個教學單元。

## 🚀 如何使用本網站

只需開啟 GitHub Pages 首頁，您將會看到動態生成的檔案清單。
* 📄 點擊 **`.html` 檔案**：可直接觀看結合 Canva 與 AI 內容的互動式教學網頁。
* 📁 點擊 **資料夾**：可進入不同主題模組（例如：基礎指令、系統權限、雲端部署等）探索更多資源。
