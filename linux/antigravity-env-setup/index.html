觀念 01 · PYTHON

為什麼要另外裝 Python？

Antigravity 啟動不用 Python，但當 AI 要幫你跑 .py 腳本、啟動 http.server 網頁預覽或使用 Python SDK 時，必須調用系統裡的 Python（建議搭配 uv）！

觀念 02 · NODE.JS & MCP

為什麼要裝 Node.js (LTS)？

除了跑現代前端網頁外，超過 80% 的 MCP 擴充工具（Model Context Protocol）都是由 AI 在背景透過 Node.js 內附的 npx 指令自動啟動！

觀念 03 · BUILT-IN IDE

還需要裝別的編輯器嗎？不用！

Antigravity IDE 本身就是內建 VS Code 核心的專業編輯器（含語法高亮、終端機、Tab 補全與 Cmd/Ctrl+I），直接拿它當主力編輯器即可！

觀念 04 · DOWNLOAD & CHECK

壓軸下載 ＋ 開機 AI 自動健檢

到 antigravity.google 下載安裝主程式後，直接貼上本頁提供的「開機健檢 Prompt」，讓 AI 自動幫你檢查所有工具並補齊缺漏！
