Windows 11 送 Log 至 Graylog

NXLog 安裝與設定互動指南

第一階段：安裝 NXLog 套件

  • 下載安裝檔：前往 NXLog 官方網站下載 NXLog Community Edition 的 Windows MSI 安裝檔。
  • 🛡️ 需管理員權限
    執行安裝：雙擊 MSI 檔案。若跳出 UAC (使用者帳戶控制) 提示，請點選「是」。
    預設安裝路徑為：C:\Program Files\nxlog

第二階段：設定 nxlog.conf

  • 🛡️ 需管理員權限
    以系統管理員身分開啟編輯器：這步非常重要！請按 Win 鍵，搜尋 Notepad，按右鍵選擇「以系統管理員身分執行」。
  • 開啟並修改檔案：在記事本開啟 C:\Program Files\nxlog\conf\nxlog.conf，清空原有內容，貼上以下設定：
📄 nxlog.conf (重點設定檔) 
# 發生嚴重錯誤時的處理機制
Panic Soft
#NoFreeOnExit TRUE

# 定義系統變數，對應安裝路徑
define ROOT     C:\Program Files\nxlog
define CERTDIR  %ROOT%\cert
define CONFDIR  %ROOT%\conf\nxlog.d
define LOGDIR   %ROOT%\data

include %CONFDIR%\*.conf
define LOGFILE  %LOGDIR%\nxlog.log
LogFile %LOGFILE%

Moduledir %ROOT%\modules
CacheDir  %ROOT%\data
Pidfile   %ROOT%\data\nxlog.pid
SpoolDir  %ROOT%\data

# ==========================================
# 擴展模組區 (將資料轉成 Graylog 支援的 GELF 格式)
# ==========================================
<Extension _gelf>
    Module xm_gelf
</Extension>

# ==========================================
# 輸入區 (Windows 事件檢視器收集)
# ==========================================
<Input in>
    Module im_msvistalog
</Input>

# ==========================================
# 輸出區 (傳送到 Graylog)
# ==========================================
<Output out>
    Module om_udp
    # 【請注意】將下方 IP 改為你真實的 Graylog Server IP
    Host 10.24.1.XXX
    Port 32201
    OutputType GELF
</Output>

# ==========================================
# 路由區 (建立資料流)
# ==========================================
<Route 1>
    Path in => out
</Route>

第三階段：啟動服務與防火牆

  • 🛡️ 需管理員權限
    重新啟動 NXLog 服務：在開始按鈕點右鍵，選擇「終端機 (系統管理員)」，輸入：

    Restart-Service nxlog

    若無紅字錯誤，代表重啟成功。
  • 防火牆檢查：確保你的 Windows 本機防火牆及網路環境，允許對外使用 UDP Port 32201 傳輸。

第四階段：驗證與除錯

  • 檢查 NXLog 內部日誌：
    開啟 C:\Program Files\nxlog\data\nxlog.log。
    出現 INFO nxlog-ce-x.x.x started 代表啟動成功；若有 ERROR，檔案內會標示是設定檔哪行有誤。
  • 檢查 Graylog 端設定：
    確保 Graylog Server 上有建立 GELF UDP 的 Input，且 Port 正確設為 32201，同時伺服器防火牆有放行該 Port。
