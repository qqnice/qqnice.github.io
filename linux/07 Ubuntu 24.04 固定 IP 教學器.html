⚠️ YAML 格式極度嚴格，請絕對遵守以下規則：

  • 絕對禁止使用 Tab 鍵，一律使用空白鍵排版。
  • 每層縮排為 2 個空白格。
  • 所有的冒號 (:) 和減號 (-) 後面必須要有一個半形空白。
/etc/netplan/50-cloud-init.yaml

套用與兩段式網路檢核步驟

步驟 1：套用設定檔

sudo netplan apply

若無錯誤訊息跳出，代表 YAML 語法正確且已生效。

步驟 2：檢查 IP 是否變更

ip a

確認指定的網卡已顯示剛剛設定的固定 IP。

步驟 3：測試對外路由與閘道 (Gateway)

ping -c 4 8.8.8.8

若會通，代表封包已順利送出網路閘道。若顯示 Unreachable，請檢查 Gateway 設定。

步驟 4：測試網域名稱解析 (DNS)

ping -c 4 www.google.com

若 8.8.8.8 會通但這個不通，代表 DNS 設定錯誤或伺服器無回應。
