🐙 GitHub 帳號、2FA 與 Antigravity AI 串接發佈實戰（學習三部曲） 免背 Git 指令・下 Prompt 自動發布網站

第 1 站：帳號與 2FA GitHub 帳號申請與兩階段驗證（2FA）互動教學 給學生與老師的逐步操作指南：申請前準備、10 步註冊與信箱驗證、TOTP 驗證器 App 與復原碼備份，附官方畫面與常見問題。 第 2 站：前置環境與下載 Antigravity 開發前置環境準備 ＆ 官方下載安裝教學 解答為什麼要另外裝 Python、Node.js (LTS) 與 Git，免另外裝編輯器的觀念說明，壓軸下載 Google Antigravity 並附上開機 AI 自動健檢 Prompt。 第 3 站：AI 串接實戰 Antigravity × GitHub：下 Prompt 就完成串接與網站發佈 免背繁瑣 Git 指令！結合 GitHub 瀏覽器 8 碼一鍵授權、7 步可複製 Prompt 模板、自訂發佈提示詞產生器與真實頁面對照。

📜 Graylog 6.0 集中式日誌收集與 SOC 資安戰情中心 Linux Rsyslog × Windows NXLog 跨平台日誌整合

STEP 1｜伺服器安裝 Graylog 6.0 部署指南（Ubuntu 24.04 SOP） Ubuntu 24.04 環境準備、MongoDB、OpenSearch / Data Node 與 Graylog 6.0 Server 標準安裝步驟。 STEP 2｜互動模擬 Graylog 資安戰情中心（SOC 互動體驗模擬） 透過互動模擬體驗 SOC 資安監控中心如何接收日誌、設定 Input、檢視儀表板與追查異常事件。 STEP 3｜Linux 端點整合 Rsyslog to Graylog 部署與進階除錯互動指南 將 Ubuntu / Linux 系統日誌透過 Rsyslog 拋送至 Graylog，含連線測試與常見收不到 Log 的除錯流程。 STEP 4｜Windows 端點概念 Windows NXLog to Graylog 整合指南 將 Windows 事件檢視器（Event Log）透過 NXLog 轉換為 GELF / Syslog 格式送進 Graylog 的架構與設定。 STEP 5｜Windows 11 實戰 Windows 11 透過 NXLog 傳送日誌至 Graylog 實戰教學 在 Windows 11 端點實際安裝 NXLog、編輯 nxlog.conf 並於 Graylog Search 驗證日誌進線。 STEP 6｜進階解析與告警 Graylog 進階操作與整合實戰（互動模擬） 進階欄位萃取（Extractors）、Pipeline 規則處理、Stream 分流與資安事件告警通知實作。

🧰 本地 AI 環境、Ubuntu 網路設定工具與雲端安全 實用產生器與架構圖解

本地 AI｜Windows WSL WSL + Ollama + Open WebUI 本地 AI 部署指南 在自己筆電或桌機的 Windows WSL2 環境中，快速架設 Ollama 本地推論引擎與 Open WebUI 聊天介面。 互動工具｜Netplan Ubuntu 24.04 固定 IP（Netplan YAML）互動產生器 輸入網卡名稱、固定 IP/遮罩、Gateway 與 DNS，即時預覽並複製零縮排錯誤的 Netplan 設定檔與套用指令。 雲端安全｜DDoS 防護 AWS Shield 防禦 DDoS 原理與架構圖解 互動圖解 AWS Shield Standard 與 Advanced 如何結合 CloudFront、Route 53 與 WAF 防禦各層級 DDoS 攻擊。
