核心運作原理

AWS Shield 如何阻止 DDoS？

AWS Shield 的核心戰略是「就近化解、全球分散、智慧過濾」。它不是讓所有洪水般的垃圾流量直衝你的單一伺服器，而是利用 AWS 分佈在全球的上百個邊緣節點（Edge Locations）與數十 Tbps 的骨幹網路，第一時間將攻擊流量就近分流（Anycast）並送入專屬硬體進行深層清洗（Scrubbing），最後只讓純淨的正常請求抵達你的應用程式。

1. Anycast 全球吸納
利用 BGP 繞送，將全球分散的殭屍流量就近引導至最近的邊緣站點，避免單點頻寬爆炸。
2. 即時微秒級清洗
底層專屬封包過濾晶片自動檢查 TCP/UDP 畸形封包、SYN 握手完整性，於邊界毫秒內丟棄（Drop）。
3. 智慧 L7 規則聯防
Shield Advanced 自動學習正常流量基線，結合 AWS WAF 即時產生阻擋規則，防禦複雜 HTTP 洪水。

AWS DDoS 多層縱深防禦架構

AWS 採用「層層削弱、內外分工」的階梯式架構，不讓惡意流量踏進 VPC 內網一步

第一道防線 (免費用戶標配)

01. AWS 邊緣網路與 Shield Standard

部署在 CloudFront CDN、Route 53 DNS 與全球邊緣接入點（Edge PoPs）。

防護層級：L3 / L4 (網路與傳輸層) 專門阻擋 SYN Flood、UDP 反射放大攻擊、ACK 洪水。
自動 SYN Proxy 握手 邊緣節點代為完成三次交握，驗證來源真偽，假封包當場丟棄。
費用：$0 (所有 AWS 客戶全自動內建)
第二道防線 (企業進階防護)

02. Shield Advanced + AWS WAF

防護 ALB、NLB、CloudFront、Route 53 與 EC2 彈性 IP，專克精密型攻擊。

防護層級：L7 (應用層深度過濾) 機器學習建立應用程式平時健康基線，自動辨識異常突發請求。
自動緩解 (Auto-Mitigation) 遇 HTTP Flood 自動生成 WAF Rate-based Rule 即時擋下特定指紋。
費用：$3,000/月 (含 WAF 吃到飽 + 專家支援)
第三道防線 (核心後端與財務保障)

03. 專屬團隊 (SRT) 與費用補償

攻擊者變更手法時由資深專家介入，並防止因 Auto Scaling 造成的百萬帳單災難。

SRT (Shield Response Team) 24/7 待命，授權專家直接進入您的 WAF 撰寫自訂攔截規則。
DDoS 成本保護 (Cost Protection) 因承受攻擊流量導致 CloudFront/ALB 暴增的費用，AWS 予以退款抵免。
保障：服務不中斷 + 荷包免破產

典型攻擊實例：Shield 如何見招拆招？

以下兩個最經典的 DDoS 場景，展示 Standard 與 Advanced 如何各司其職：

攻擊實例 1 Layer 4 - SYN Flood 洪水

駭客調動 20 萬台物聯網設備，每秒發動 800 Gbps 虛假連線

攻擊者偽造隨機來源 IP，持續發送 TCP SYN 封包，試圖耗盡伺服器連線隊列。

🛡️ AWS Shield Standard 的防禦動作：
  1. 流量在距離各國殭屍最近的 CloudFront 邊緣節點被吸收。
  2. Shield 邊緣硬體執行 SYN Cookies / SYN Proxy 機制，要求客戶端完成驗證。
  3. 因為偽造 IP 的殭屍電腦無法回應 ACK，99.9% 惡意封包在邊緣 0.001 秒內直接被拋棄（Drop）。
  4. 抵達 EC2 的封包數量為 0，後端工程師甚至完全不知情，業務平穩運作。
攻擊實例 2 Layer 7 - 搶票 API 搜尋洪水

演唱會開賣！駭客偽裝正常瀏覽器，狂刷「複雜票價查詢 API」

每一個請求皆為完整 TCP 連線與合法 HTTP 請求，單看封包完全正常，但每秒 50 萬次查詢會讓資料庫瞬間當機。

💎 AWS Shield Advanced + WAF 的防禦動作：
  1. Shield Advanced 的異常檢測演算法察覺該 API 流量偏離日常基線達 1,200%。
  2. 自動觸發自動緩解機制（Automatic Layer 7 Mitigation），分析攻擊特徵（如 User-Agent 畸形、特定標頭、單 IP 請求頻率）。
  3. 5 秒內自動在 AWS WAF 建立封鎖規則，向惡意請求回傳 429 / 403，或自動派發 JavaScript 驗證挑戰（CAPTCHA）。
  4. 真正想買票的歌迷順利購票，資料庫負載維持在安全範圍內。
