Windows NXLog ➔ Graylog 整合指南

部署步驟

  • 1
    修改設定檔
  • 2
    重啟 NXLog 服務
  • 3
    Graylog 接收設定
  • !
    故障排除 (無法啟動)

第一步：產生並修改 nxlog.conf

請在下方輸入你的 Graylog 伺服器資訊，系統會自動為你產生正確的設定檔。預設路徑為 C:\Program Files\nxlog\conf\nxlog.conf。

第二步：重新啟動 NXLog 服務

設定檔儲存後，必須重新啟動服務才會生效。強烈建議使用系統管理員身分執行命令提示字元 (CMD) 來操作。

net stop nxlog
net start nxlog

第三步：在 Graylog 端設定接收 (Input)

  1. 登入 Graylog 網頁管理介面。
  2. 前往頂部選單 System ➔ Inputs。
  3. 在 Select Input 下拉選單中，選擇 GELF UDP。
  4. 點擊 Launch new input 按鈕。
  5. 填寫關鍵資訊：
    • Title: Windows_NXLog (自訂名稱)
    • Bind address: 0.0.0.0 (保持預設)
    • Port: 32201 (必須與 nxlog.conf 一致)
  6. 點擊 Save。確認狀態轉為綠色的 Running。

故障排除：服務無法啟動怎麼辦？

如果執行 `net start nxlog` 失敗，通常是因為設定檔有語法錯誤或路徑錯誤。請依照以下步驟排查：

1. 查看 NXLog 內部錯誤日誌 (最快的方法)

用記事本打開：C:\Program Files\nxlog\data\nxlog.log

捲動到檔案的最底下，尋找帶有 ERROR 或 failed 的字眼。它通常會精準告訴你是哪一行寫錯了（例如：config error at line 25）。

2. 讓 NXLog 幫你抓蟲 (使用 -v 參數)

以系統管理員身分開啟 CMD，執行以下指令驗證設定檔語法：

"C:\Program Files\nxlog\nxlog.exe" -v

如果畫面顯示錯誤，請針對該行進行修改；如果什麼都沒顯示或顯示 OK，代表語法無誤。

3. 檢查三個最常見的「隱形地雷」
  • 安裝路徑不對：
    如果你安裝的是 32 位元版，預設路徑其實是 C:\Program Files (x86)\nxlog。請確保設定檔頂部的 define ROOT 與你的實際資料夾一致。
  • 混入了全形空白：
    從網頁複製時常會帶入中文字的全形空白（　）。NXLog 看不懂這個，請確保縮排使用的是半形空白或 Tab。
  • 標籤沒有閉合：
    檢查是否所有的 <Input in> 都有對應的 </Input>。少一個斜線就會報錯。
