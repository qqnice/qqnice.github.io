Graylog + MongoDB + OpenSearch 完整部署指南

本指南將協助您在 VirtualBox (Ubuntu 24.04 Server) 建立 Graylog 日誌伺服器，並設定 Windows 11 轉發日誌。

! 互動式環境設定

請在下方輸入您的 Ubuntu VM 被分配到的 IP。本文件的設定檔與指令將會自動即時更新。

第一階段：VirtualBox 網路設定

由於您的環境是由 DHCP 發配 10.24.1.0/24，請確保 VM 網卡處於橋接模式並設定 MAC 亂數。

  1. 開啟 VirtualBox，對著 Ubuntu 24.04 VM 點擊右鍵選擇 「設定」(Settings)。
  2. 進入 「網路」(Network) 選單，選擇 「介面卡 1」(Adapter 1)。
  3. 將 「附加到」(Attached to) 改為 「橋接介面卡」(Bridged Adapter)。
  4. 點擊下方的 「進階」(Advanced)，在 「MAC 位址」 右側點擊 「產生新的隨機 MAC 位址」。
  5. 確認 「混雜模式」 設為「拒絕」，點擊「確定」並啟動 VM。
  6. 開機後使用 ip a 指令確認是否獲取到 10.24.1.x 網段的 IP。

第二階段：系統基礎與依賴套件安裝

更新系統並安裝 Graylog 運行所需的 Java 17 及其他工具。

sudo apt update && sudo apt upgrade -y
sudo apt install -y apt-transport-https openjdk-17-jre-headless uuid-runtime pwgen dirmngr gnupg wget curl

第三階段：安裝與設定 MongoDB 7.0

1. 匯入金鑰並加入 Repository：

curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

2. 安裝並啟動 MongoDB：

sudo apt update
sudo apt install -y mongodb-org
sudo systemctl daemon-reload
sudo systemctl enable --now mongod

第四階段：安裝與設定 OpenSearch 2.x

1. 匯入金鑰並安裝 OpenSearch：

curl -o- https://artifacts.opensearch.org/publickeys/opensearch.pgp | sudo gpg --dearmor --batch --yes -o /usr/share/keyrings/opensearch-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/opensearch-keyring.gpg] https://artifacts.opensearch.org/releases/bundle/opensearch/2.x/apt stable main" | sudo tee /etc/apt/sources.list.d/opensearch-2.x.list

sudo apt update
sudo env OPENSEARCH_INITIAL_ADMIN_PASSWORD=$(tr -dc A-Za-z0-9

2. 配置 OpenSearch (/etc/opensearch/opensearch.yml)：

將原內容清空，填入以下設定以配合 Graylog 運作（單節點並關閉安全插件）：

cluster.name: graylog
node.name: ${HOSTNAME}
path.data: /var/lib/opensearch
path.logs: /var/log/opensearch
discovery.type: single-node
network.host: 127.0.0.1
action.auto_create_index: false
plugins.security.disabled: true

3. 啟動 OpenSearch：

sudo systemctl enable --now opensearch

第五階段：安裝與設定 Graylog Server

1. 安裝 Graylog 6.0：

wget https://packages.graylog2.org/repo/packages/graylog-6.0-repository_latest.deb
sudo dpkg -i graylog-6.0-repository_latest.deb
sudo apt update
sudo apt install -y graylog-server

2. 產生金鑰與設定密碼 1qaz%TGB：

分別執行以下指令，並記下產生的字串：

# 產生 96 字元的 password_secret
pwgen -N 1 -s 96

# 將預設密碼 1qaz%TGB 轉為 SHA-256 雜湊值
echo -n "1qaz%TGB" | sha256sum

3. 配置 Graylog (/etc/graylog/server/server.conf)：

修改設定檔，填入剛才產生的字串，預設帳號為 admin：

password_secret = <填入剛才 pwgen 產生的 96 字元>
root_password_sha2 = <填入剛才 sha256sum 產生的雜湊值>
root_username = admin
http_bind_address = 0.0.0.0:9000

4. 啟動 Graylog：

sudo systemctl daemon-reload
sudo systemctl enable --now graylog-server

第六階段：設定接收 Windows 11 Log

A 在 Graylog 開啟 Syslog Input

  1. 打開瀏覽器，前往 http://10.24.1.x:9000。
  2. 使用帳號 admin 與密碼 1qaz%TGB 登入。
  3. 導覽至 System -> Inputs。
  4. 下拉選擇 Syslog UDP，點擊 Launch new input。
  5. 填寫資訊：Title: Windows 11 Logs, Bind address: 0.0.0.0, Port: 1514。
  6. 點擊 Save。

B 在 Windows 11 端設定轉發 (NXLog)

  1. 在 Windows 11 下載並安裝 NXLog Community Edition。
  2. 使用系統管理員權限編輯：C:\Program Files\nxlog\conf\nxlog.conf。
  3. 將內容替換為以下配置：
Panic Soft

define ROOT     C:\Program Files\nxlog
define CERTDIR  %ROOT%\cert
define CONFDIR  %ROOT%\conf
define LOGDIR   %ROOT%\data
define LOGFILE  %LOGDIR%\nxlog.log
LogFile %LOGFILE%

Moduledir %ROOT%\modules
CacheDir  %ROOT%\data
Pidfile   %ROOT%\data\nxlog.pid
SpoolDir  %ROOT%\data

<Extension _syslog>
    Module      xm_syslog
</Extension>

<Input in>
    Module      im_msvistalog
</Input>

<Output out>
    Module      om_udp
    Host        10.24.1.x  # 對應您的 Ubuntu VM IP
    Port        1514       # 對應 Graylog 設定的 Port
    Exec        to_syslog_snare();
</Output>

<Route 1>
    Path        in => out
</Route>

4. 在 Windows 11 的「服務」(services.msc) 中，重新啟動 nxlog 服務即可。
