本地 AI 部署

在 Windows WSL 上打造專屬的 AI 對話平台。

完成進度 0/4
2. 安裝 Docker Desktop 3. 安裝 Ollama 與 Gemma 模型 4. 啟動 Open WebUI

請注意：目前官方並未發布「Gemma 4」，本指南採用最新且效能極佳的輕量級 Gemma 2 2B 模型。

1

安裝並驗證 Ubuntu 24.04 (WSL)

環境：Windows PowerShell (請以系統管理員身分執行)

Administrator: Windows PowerShell
wsl --install -d Ubuntu-24.04

👉 安裝完成後可能需要重新啟動電腦。重啟後 Ubuntu 視窗會彈出，請依照畫面設定使用者名稱與密碼。

環境：Ubuntu 終端機 (驗證版本)

ubuntu@wsl
cat /etc/os-release

👉 確認輸出內容包含 PRETTY_NAME="Ubuntu 24.04 LTS"。

2

安裝 Docker Desktop (Windows 端)

下載與安裝

請前往 Docker 官方網站 下載 Docker Desktop for Windows 並按照一般軟體流程完成安裝。

關鍵設定：開啟 WSL 整合

  1. 啟動 Docker Desktop 應用程式。
  2. 點擊右上角的 齒輪圖示 (Settings)。
  3. 左側選單進入 Resources → WSL integration。
  4. 確保 "Enable integration with my default WSL distro" 有打勾。
  5. 在下方的清單中，找到 Ubuntu-24.04 並將其開關切換為 開啟 (On)。
  6. 點擊右下角的 Apply & restart。
3

安裝 Ollama 與 Gemma 模型

以下指令請全部在 Ubuntu 終端機 內執行。

1. 一鍵安裝 Ollama

curl -fsSL https://ollama.com/install.sh | sh

2. 下載並執行 Gemma 2 2B 模型

ollama run gemma2:2b

👉 第一次執行需下載模型檔案（約 1.6GB），請耐心等待。

3. 驗證本地問答 (CLI 介面)

...下載完成後會進入對話模式...
>>> 你好！請用繁體中文介紹一下你自己。
你好！我是一個大型語言模型，由 Google 訓練...
>>> 輸入 /bye 或按下 Ctrl+D 退出問答模式
4

啟動 Open WebUI 網頁介面

環境：Ubuntu 終端機 (確保 Docker 已整合啟動)

docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

開始體驗您的本地 AI

容器啟動完成後，請打開您的網頁瀏覽器，前往以下網址：

訪問 http://localhost:3000
  • 首次進入需註冊管理員帳號 (資料完全保存在您的電腦)。
  • 登入後，在畫面上方中央選擇 gemma2:2b 模型。
  • 開始您的私人 AI 對話體驗！

恭喜完成所有部署步驟！

您現在已經擁有一個強大且隱私安全的本地端 AI 平台。

AI 名詞解釋小百科

快速了解本教學與 AI 領域中常見的重要專業術語。

核心概念

AI (人工智慧)

電腦科學的一個分支，致力於創造能模擬人類智能行為（如學習、推理、解決問題、語言理解）的系統與技術總稱。

機械學習 (Machine Learning)

AI 的一個重要子集。指不透過明確編寫指令，而是透過演算法讓電腦從「大量資料」中自動學習規律，並做出預測或決策的技術。

深度學習 (Deep Learning)

機械學習的進階分支。它建構了多層的「人工神經網路」（靈感來自人腦結構），能處理極其複雜的非結構化資料，如圖像辨識與自然語言處理。

LLM (大型語言模型)

Large Language Model。指參數規模極大、使用海量文本訓練出來的深度學習模型。它們能夠理解上下文、進行對話、翻譯和生成極具邏輯的人類文章（例如 ChatGPT 背後的模型）。

AI Agent (AI 代理)

具備「自主行動能力」的進階 AI 系統。它不僅是被動回答問題，還能根據使用者給予的目標，自主規劃步驟、拆解任務，並呼叫外部工具（如搜尋網路、執行程式碼、操作軟體）來自動完成複雜的工作。

模型與工具

Ollama

一個廣受歡迎的開源工具，讓開發者與一般使用者能透過簡單的指令，輕鬆在本地端電腦上下載、管理並執行各種大型語言模型。

Llama (常拼作 Lama)

由 Meta (前 Facebook) 開源發布的大型語言模型系列。因其效能強大且開放原始碼，帶動了全球開源 AI 社群的爆炸性成長。

Gemma (常拼作 Gamma)

由 Google 推出的輕量級開源模型。它與強大的 Gemini 共享相同的底層技術，專為在一般筆電或工作站上高效運行而設計。

Codex (Code dex)

由 OpenAI 訓練的特殊模型，專精於解析和生成程式碼。它能將自然語言直接轉換為可執行的程式，是 GitHub Copilot 等寫程式輔助工具背後的基礎核心技術。

龍蝦 OpenClaw

這是一個有趣的名詞！在硬體與機器人領域，OpenClaw 是一個知名的開源 3D 列印機械爪專案；在 AI 軟體界，這類名稱常被社群用來代稱結合了「視覺辨識 AI」與「機器手臂控制」的開源夾取計畫，或是指代某種網頁資料抓取 (Crawling) 結合 AI 分析的工具暱稱。

環境與架構

地端 AI (Local AI)

相對於「雲端 AI (如網頁版 ChatGPT)」。指將 AI 模型直接安裝並運行在自己的實體電腦上。優點是資料絕對隱私、不需網路連線、免費且可高度客製化。

WSL (Windows Subsystem for Linux)

微軟開發的「Windows 內建 Linux 子系統」。它讓 Windows 使用者無需安裝笨重的虛擬機，就能直接且流暢地運行原生的 Linux 系統（如 Ubuntu），是目前在 Windows 開發 AI 應用的最佳捷徑。
