安全護欄：發布前保留「人工審核節點 (Human-in-the-Loop)」

行政人員專注於『內容確認』與拍板核准，系統接續自動化整理與發布。草稿做完不等於已發布，等待是正常工作狀態，嚴格防範越權風險。

⚠️ 行政同仁必看：關鍵前置設定與避坑守則

📬 學校信箱自動轉寄 關鍵步驟

若想讓 AI 幫忙收信，務必進入 Mail2000 ➔ 個人設定 ➔ 信件處理 ➔ 自動轉寄 到 Gmail（最好是 gm.nutc.edu.tw）。並務必實測寄信確認 Gmail 收得到！

💻 地端執行保護隱私 資安第一

主管課表比對戰情表、考生聯絡電話戰情室，在本機地端執行即可，不需串接 Tool 連接外網，確保考生個資與內部課表 100% 不外洩。

⚙️ 網頁對話 vs Desktop 軟體安裝

工作坊建議安裝 Desktop 專用桌面版軟體，操作更順暢。技術工作或複雜流水線可搭配 Codex 與 Google Antigravity。
